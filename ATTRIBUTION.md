# Attribution

If you use Frakment in your project, add this to your README (or a visible footer):

> Based on [Frakment](https://github.com/hanshapd/frakment) by [hanshapd](https://github.com/hanshapd).

That is the only thing we ask. You do not need to link to every file, and the wording does not have to match exactly - just make sure the credit is clear and links back to the original repository.

## What counts as clear attribution

- **Good**: a README line, a footer link, or an "About" section that names Frakment and links to the repo.
- **Not enough**: hiding the credit in a source comment, minified HTML, or a page nobody reads.

If you are unsure whether your attribution is visible enough, open an issue and ask.

## Commercial use

Before using Frakment for commercial purposes, satisfy **one** of the following:

1. **Get one pull request merged** into [hanshapd/frakment](https://github.com/hanshapd/frakment). Any substantive change counts: typo, docs, test, translation, bug fix, feature.
2. **Sponsor the project once** via [GitHub Sponsors](https://github.com/sponsors/hanshapd). Any amount from $1.
3. **Get written permission** from [hanshapd](https://github.com/hanshapd) on GitHub.

After **one** qualifying contribution, commercial use is permanently allowed for you (or your entity). No repeat contribution is needed for future projects.

See [LICENSE](./LICENSE) Section 4 for the exact rules.

## Non-commercial use

Personal, educational, and internal-non-revenue use require **no contribution**. Attribution is the only requirement.
