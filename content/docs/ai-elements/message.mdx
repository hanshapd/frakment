## Usage

```tsx title="message.tsx"
import { Message, MessageContent } from "@/components/ui/message";
import { Bubble, BubbleContent } from "@/components/ui/bubble";
```

```tsx title="message.tsx"
<Message align="end">
  <MessageContent>
    <Bubble variant="muted" align="end">
      <BubbleContent>{"Why is the dashboard slow?"}</BubbleContent>
    </Bubble>
  </MessageContent>
</Message>
```

## Anatomy

```tsx title="messagegroup.tsx"
<MessageGroup>
  <Message>
    <MessageAvatar />
    <MessageContent>
      <MessageHeader />
      {/* bubbles, text, code, etc. */}
      <MessageFooter />
    </MessageContent>
  </Message>
</MessageGroup>
```

- **MessageGroup** — vertical stack of messages, 8px gap
- **Message** — one turn, controls alignment
- **MessageAvatar** — 32px circular avatar, bottom-aligned
- **MessageContent** — flex column with 10px gap
- **MessageHeader** — small muted text above content (e.g. name, time)
- **MessageFooter** — small muted text below content (e.g. actions)

## Alignment

`align="start"` for received, `align="end"` for sent. When `end`, children with `data-slot` push to the end of the row.

### Message

### MessageAvatar

Auto-translates up 32px when a **MessageFooter** is present, keeping the avatar aligned to the bubble. Extends `React.ComponentProps<"div">`.

### MessageContent / MessageHeader / MessageFooter

Extend `React.ComponentProps<"div">`. Header and footer render in 12px muted text.

## Accessibility

- Use a semantic role on the outer group if the conversation is a list (`role="log"` for live streams).
- `MessageAvatar` is decorative unless it carries a name — pair it with `MessageHeader` for screen readers.
- Footer actions should have `aria-label` if they are icon-only.
