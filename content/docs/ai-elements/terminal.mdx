Terminal renders a list of shell commands as collapsible trace rows. Each command streams character by character, output appears line by line, and a spinner flips to a checkmark when the command finishes.

Built on top of [Trace](/docs/ai-elements/trace) and [Code Block](/docs/components/code-block), so the visual language stays consistent with the rest of the registry.

## Anatomy

A terminal has three visible parts.

- **Trace list** — the outer `Trace` container, one row per command
- **Trigger row** — icon, spinner or checkmark, and the command text
- **Output panel** — collapsible `CodeBlock` that streams stdout

### Terminal

Extends `React.ComponentProps<"div">`. Renders as a `Trace` container. No custom props — pass `TerminalCommand` children.

## Accessibility

- The trigger uses `CollapsibleTrigger`, so keyboard navigation works with `Tab` and `Enter`/`Space`.
- The trigger row exposes the command text as its accessible label.
- Icons are decorative and inherit `aria-hidden` from Lucide defaults.
- Output renders inside a focusable `<pre>` — screen readers can select and copy stdout.
