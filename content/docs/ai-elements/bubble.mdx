## Usage

```tsx title="bubble.tsx"
import { Bubble, BubbleContent } from "@/components/ui/bubble";
```

```tsx title="bubble.tsx"
<Bubble variant="muted" align="end">
  <BubbleContent>{"Why is the dashboard slow?"}</BubbleContent>
</Bubble>
```

## Anatomy

```tsx title="bubblegroup.tsx"
<BubbleGroup>
  <Bubble>
    <BubbleContent />
    <BubbleReactions />
  </Bubble>
</BubbleGroup>
```

- **BubbleGroup** — vertical stack with 8px gap
- **Bubble** — bubble root, controls variant and alignment
- **BubbleContent** — the visible surface (border, padding, background)
- **BubbleReactions** — floating pill for emoji reactions

### BubbleContent

Extends `React.ComponentProps<"div">` with `asChild` support. When true, renders as a `Slot`, letting the content become a `<button>` or `<a>` for interactive bubbles.

## Accessibility

- Use `asChild` to make a bubble a button or link when it should be clickable.
- Reactions should have `aria-label` for screen readers — emoji alone is not descriptive.
- Alignment is visual only; do not rely on it to convey sender role.
