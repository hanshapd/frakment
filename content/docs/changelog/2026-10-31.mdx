### Terminal

Terminal renders a list of shell commands as collapsible trace rows. Each command streams character by character, output appears line by line, and a spinner flips to a checkmark when the command finishes. It is the first component that ships with registry dependencies instead of being standalone.

#### Installation

<Steps>
  <Step>Install the component</Step>

```bash
npx frakment add terminal
```

<Step>
  Install registry dependencies first (the CLI does this automatically)
</Step>

```bash
npx frakment add trace code-block
```

<Step>Use it in your app</Step>

```tsx
import { Terminal, TerminalCommand } from "@/components/ui/terminal";
```

</Steps>

#### What it looks like

A user asks for a chat bubble, the agent runs commands, and the terminal streams the output live.

#### Minimal usage

```tsx
<Terminal>
  <TerminalCommand
    command="npm run registry:build"
    output={"✓ Built 15 components"}
  />
</Terminal>
```

Pass `status="running"` while a command executes, then flip to `"done"` when it finishes. See the [Terminal docs](/docs/ai-elements/terminal) for the full API reference.

### MCP fix

`getSponsors()` no longer crashes when the GraphQL response is missing `user.sponsorshipsAsMaintainer`. Instead it returns an empty array so the page still renders.

```ts
const nodes = json.data?.user?.sponsorshipsAsMaintainer?.nodes ?? [];
```

This means sponsors without an active GitHub Sponsors account see the empty state instead of an error boundary.
