Avatar renders a circular user image with a text fallback when the image fails to load or is missing. It is built on top of Radix's Avatar primitive, with a small composable API for badges, groups, and counts.

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";
```

```tsx
<Avatar>
  <AvatarImage src="/avatars/me.avif" alt="@me" />
  <AvatarFallback>{"ME"}</AvatarFallback>
</Avatar>
```

## Anatomy

```tsx
<Avatar>
  <AvatarImage />
  <AvatarFallback />
  <AvatarBadge />
</Avatar>

<AvatarGroup>
  <Avatar />
  <Avatar />
  <AvatarGroupCount />
</AvatarGroup>
```

- **Avatar** — circular root, controls size (`sm` | `default` | `lg`)
- **AvatarImage** — the actual image, `object-cover` and `rounded-full`
- **AvatarFallback** — initial text shown while loading or on error
- **AvatarBadge** — small dot at the bottom-right for online or status
- **AvatarGroup** — overlapping stack with -8px gap and background ring
- **AvatarGroupCount** — "+N" badge at the end of a group

## Sizes

Three sizes are available via the `size` prop. The default is 32px, `sm` is 24px, `lg` is 40px.

### Overlap direction

Avatars stack left-to-right with each one overlapping the next by 8px. The
background ring (`ring-2 ring-background`) keeps edges visible. If you need
right-to-left stacking, wrap the group with `flex-row-reverse`.

## Facing direction

All demo avatars face left by default (`-l`). Use `male-r` alone when you need a single right-facing avatar — never mix `-l` and `-r` in the same row.

## API Reference

### Avatar

<PropsTable
  rows={[
    {
      name: "size",
      type: "sm | default | lg",
      default: "default",
      description: "Controls the diameter of the avatar (24px / 32px / 40px).",
    },
  ]}
/>

### AvatarImage

Extends Radix `Avatar.Image`. Requires `src` and `alt`. Applies `object-cover` and `rounded-full`.

### AvatarFallback

Extends Radix `Avatar.Fallback`. Renders children when the image is missing or fails. Use 2–3 character initials.

### AvatarBadge

Extends `React.ComponentProps<"span">`. Positioned absolutely at the bottom-right. Pass a background color with `className` (e.g., `bg-green-600`).

### AvatarGroup / AvatarGroupCount

Extend `React.ComponentProps<"div">`. Group applies `-space-x-2` and a 2px background ring per avatar. Count inherits the size of the group's avatars via `has-data-[size=lg]`.

## Accessibility

- Always pass `alt` on **AvatarImage** — describe the person, not the file. Use `@username` for handles.
- **AvatarFallback** initials act as a visual label but are not read as a name. If the avatar has semantic meaning, wrap the group in a container with `aria-label`.
- **AvatarBadge** is decorative. Convey the status in text when it matters (e.g., "Online").
- **AvatarGroup** should have an accessible label like `aria-label="3 participants"` when it summarizes a list.
