Spinner is a thin wrapper around Lucide's loader icons. It carries `role="status"` and `aria-label="Loading"` so screen readers announce a live loading state.

Two shapes are available: `default` (a circular arc, from `LoaderCircleIcon`) and `spoke` (a sunburst, from `LoaderIcon`).

## Shapes

`default` renders a circular arc (`LoaderCircleIcon`, formerly `Loader2Icon`). `spoke` renders a sunburst (`LoaderIcon`).

## Button

Add a spinner to a button. Place it **before** the label with `data-icon="inline-start"`, or **after** with `data-icon="inline-end"` — the button uses this attribute for spacing.

<ComponentPreview name="spinner" title="spinner.tsx">
  <div className="flex flex-wrap items-center gap-3">
    <Button disabled>
      <Spinner data-icon="inline-start" />
      Processing
    </Button>
    <Button variant="outline" disabled>
      <Spinner data-icon="inline-start" />
      Saving
    </Button>
    <Button variant="secondary" disabled>
      Loading
      <Spinner data-icon="inline-end" />
    </Button>
  </div>
</ComponentPreview>

Extends `React.ComponentProps<"svg">`. Defaults: `size-4`, `animate-spin`, `role="status"`, `aria-label="Loading"`.

## Accessibility

- Renders `role="status"` and `aria-label="Loading"` by default — screen readers treat it as a live region.
- Pair with visible text for clarity when the loading state has semantic meaning.
- `animate-spin` respects `prefers-reduced-motion`.
- When placed inside `Button` or `Badge`, keep `data-icon="inline-start"` or `"inline-end"` so the gap matches the surrounding component.
