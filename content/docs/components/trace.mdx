## Anatomy

```tsx
<Trace>
  <TraceLine>
    <TraceIcon />
    <TraceTitle />
    <TraceDescription />
  </TraceLine>
</Trace>
```

- **Trace** — flex column, 4px gap, full width
- **TraceLine** — inline row with icon and title, accepts `status`
- **TraceIcon** — 16px icon container, `aria-hidden`
- **TraceTitle** — truncated title, accessible name
- **TraceDescription** — small muted secondary text on the right

## Status

Use `status` on **TraceLine** to convey state without extra markup.

| Status    | Effect                              |
| :-------- | :---------------------------------- |
| `running` | Foreground color, shimmer on title  |
| `error`   | Destructive color                   |
| `pending` | 60% opacity                         |

## API Reference

### Trace / TraceIcon / TraceTitle / TraceDescription

Extend `React.ComponentProps<"div">` / `"span">`. **TraceIcon** is `aria-hidden`.

### TraceLine

<PropsTable
  rows={[
    {
      name: "status",
      type: "running | error | pending",
      description: "Controls color and shimmer behavior of the line.",
    },
  ]}
/>

### TraceCollapsible

Extends Radix `Collapsible.Root`. Supports `open`, `defaultOpen`, `onOpenChange`.

### TraceCollapsibleTrigger

Extends Radix `Collapsible.Trigger`. Chevron rotates 90° when open.

### TraceCollapsibleContent

Extends Radix `Collapsible.Content`. Animates height and opacity via `motion/react`.

## Accessibility

- `TraceIcon` is `aria-hidden`. Use `TraceTitle` as the accessible name — write it as a sentence.
- Status is conveyed by icon shape and color, not color alone.
- `prefers-reduced-motion` disables shimmer and collapse animation.
