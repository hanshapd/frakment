Pulse Status is the inline health indicator used inside Pulse. It renders a color-coded icon and text label that communicates the current state of a service at a glance.

## Installation

```bash
npx frakment add pulse-status
```

## Usage

```tsx
import { PulseStatus } from "@/components/ui/pulse-status";

<PulseStatus status="up" />;
```

By default, the label follows the status. Pass `label` or `count` to override the text.

## Anatomy

Pulse Status has two parts: a colored icon and a text label.

<ComponentPreview name="pulse-status" title="pulse-status.tsx">
  <div className="flex flex-col items-start gap-3 p-6">
    <PulseStatus status="up" />
    <PulseStatus status="degraded" />
    <PulseStatus status="down" />
  </div>
</ComponentPreview>

- **Icon** — the state marker (check, warning, cross) in the status color
- **Label** — the descriptive text in the status color

Both share the same color token, so they always stay in sync.

## States

Three states are supported.

| Status     | Icon          | Default label           | Color   |
| :--------- | :------------ | :---------------------- | :------ |
| `up`       | CircleCheck   | All systems operational | Emerald |
| `degraded` | TriangleAlert | Degraded                | Amber   |
| `down`     | X             | Outage                  | Rose    |

## With count

Pass `count` to show the number of affected services instead of the default label. The plural form is applied automatically.

<ComponentPreview name="pulse-status" title="pulse-status.tsx">
  <div className="flex flex-col items-start gap-3 p-6">
    <PulseStatus status="degraded" count={1} />
    <PulseStatus status="degraded" count={2} />
    <PulseStatus status="degraded" count={5} />
  </div>
</ComponentPreview>

```tsx
<PulseStatus status="degraded" count={1} />
// → "1 service affected"

<PulseStatus status="degraded" count={5} />
// → "5 services affected"
```

## With custom label

Pass `label` to fully override the text. Useful when you have a specific message for a specific state.

<ComponentPreview name="pulse-status" title="pulse-status.tsx">
  <div className="flex flex-col items-start gap-3 p-6">
    <PulseStatus status="up" label="All regions healthy" />
    <PulseStatus status="degraded" label="Elevated latency in eu-west" />
    <PulseStatus status="down" label="API is unreachable" />
  </div>
</ComponentPreview>

```tsx
<PulseStatus status="down" label="API is unreachable" />
```

## Accessibility

- The icon is marked `aria-hidden` so screen readers only announce the label text. This avoids redundant "check icon, All systems operational".
- Color is paired with icon shape and text label. The state is never conveyed by color alone — a deliberate requirement for status indicators that must pass colorblindness checks.
- The paragraph element preserves the semantic role of a text label. It is not a button or a link, so it does not appear in the tab order.
- When overriding with `label`, make sure the custom text still describes the state. Prefer "Elevated latency in eu-west" over "Something's wrong".
