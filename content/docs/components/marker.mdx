
```tsx
<Marker>
  <MarkerIcon>
    <CheckIcon />
  </MarkerIcon>
  <MarkerContent>{"Saved just now"}</MarkerContent>
</Marker>
```

## Anatomy

```tsx
<Marker>
  <MarkerIcon />
  <MarkerContent />
</Marker>
```

- **Marker** — root row, controls variant (`default` | `border` | `separator`) and `asChild`
- **MarkerIcon** — 16px icon slot, `aria-hidden`
- **MarkerContent** — the visible label, wraps inline links with underline

## Links and buttons

Use `asChild` to render the marker as a link or button. The whole row becomes clickable and keyboard-focusable.

### MarkerIcon

Extends `React.ComponentProps<"span">`. `aria-hidden`. Sizes child SVG to 16px unless overridden.

### MarkerContent

Extends `React.ComponentProps<"span">`. Wraps inline links with underline and hover color. Add `className="shimmer"` for animated streaming text.

## Accessibility

- Pass `role="status"` to `Marker` when it announces a live change (typing, syncing, running).
- `MarkerIcon` is `aria-hidden` — the meaning lives in `MarkerContent`.
- For `asChild` markers, use `<a href>` for navigation and `<button type="button">` for actions so keyboard and screen readers behave correctly.
- With `prefers-reduced-motion`, the shimmer animation stops automatically.
