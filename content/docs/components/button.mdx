## Anatomy

A button is a single element with an optional icon on either side of a text label.

<ComponentPreview name="button" title="button.tsx">
  <div className="flex flex-wrap items-center justify-center gap-3">
    <Button>Text only</Button>
    <Button>
      <CheckIcon />
      With icon
    </Button>
    <Button size="icon" aria-label="Add">
      <PlusIcon />
    </Button>
  </div>
</ComponentPreview>

- **Surface** — background, border, and radius following the variant
- **Text** — 14px, medium weight, nowrap
- **Icon** — sized to 16px by `[&_svg]:size-4`

## Variants

### Default

The primary variant, intended for the most important action on a page.

<ComponentPreview name="button" title="button.tsx">
  <Button>Default</Button>
</ComponentPreview>

### Secondary

Intended for actions of lesser prominence.

<ComponentPreview name="button" title="button.tsx">
  <Button variant="secondary">Secondary</Button>
</ComponentPreview>

### Outline

Renders with a border and a transparent background.

<ComponentPreview name="button" title="button.tsx">
  <Button variant="outline">Outline</Button>
</ComponentPreview>

### Ghost

Renders without a border. Background applies only on hover.

<ComponentPreview name="button" title="button.tsx">
  <Button variant="ghost">Ghost</Button>
</ComponentPreview>

### Destructive

Intended for destructive or irreversible actions.

<ComponentPreview name="button" title="button.tsx">
  <Button variant="destructive">Destructive</Button>
</ComponentPreview>

### Link

Renders as inline text with an underline on hover.

<ComponentPreview name="button" title="button.tsx">
  <Button variant="link">Link</Button>
</ComponentPreview>

Use the `size` prop to control the dimensions of a text button.

| Size      | Height | Padding |
| :-------- | :----- | :------ |
| `sm`      | 32px   | `px-3`  |
| `default` | 36px   | `px-4`  |
| `lg`      | 40px   | `px-6`  |

## Accessibility

- Set `type="button"` on buttons that are not intended to submit a form.
- Provide an `aria-label` on icon-only buttons.
- `disabled` removes the button from the tab order.
- Default color tokens satisfy WCAG 2.1 AA contrast.

## Best Practices

- **Use one primary button per surface.**
- **Prefer `size="sm"` inside toolbars.**
- **Never rely on color alone.**
- **Use `asChild` for links, not buttons.**
- **Reserve `destructive` for irreversible actions.**
