Item is a flexible row primitive for grouping media, content, and actions. Use it for settings lists, activity feeds, user rows, or any horizontal layout with a leading visual and trailing controls.

## Usage

```tsx
import { Item, ItemContent, ItemMedia, ItemTitle } from "@/components/ui/item";
```

```tsx
<Item>
  <ItemMedia>{"JS"}</ItemMedia>
  <ItemContent>
    <ItemTitle>{"Jane Smith"}</ItemTitle>
  </ItemContent>
</Item>
```

## Anatomy

```tsx
<ItemGroup>
  <Item>
    <ItemMedia />
    <ItemContent>
      <ItemTitle />
      <ItemDescription />
    </ItemContent>
    <ItemActions />
  </Item>
</ItemGroup>
```

- **Item** — row root, controls variant and `asChild`
- **ItemGroup** — vertical stack of items, 8px gap
- **ItemMedia** — leading visual (icon, avatar, badge)
- **ItemContent** — flexible content area, can appear multiple times
- **ItemTitle** — one-line truncated title
- **ItemDescription** — muted secondary text
- **ItemActions** — trailing actions (button, badge, amount)

## Variants

Three styles: `default` (bordered card), `outline` (transparent with border), `muted` (soft background, no border).

### ItemMedia / ItemContent / ItemTitle / ItemDescription / ItemActions

Extend `React.ComponentProps<"div">`. Each maps to a `data-slot` attribute for CSS targeting.

## Accessibility

- `Item` renders a `<div>` — for interactive rows, use `asChild` with `<a>` or `<button>` so keyboard and screen readers work.
- `ItemMedia` should be `aria-hidden` when the visual is decorative (e.g., a status dot).
- `ItemTitle` acts as the accessible name — write it as a short label.
