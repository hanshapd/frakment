## Installation

```bash
npx frakment add voice-glow
```

## Usage

```tsx
import { VoiceBeam } from "@/components/ui/voice-glow";

<VoiceBeam colorVariant="mono" idle={0.3} type="default">
  <div className="w-[350px] rounded-xl border bg-card p-6">Ask anything</div>
</VoiceBeam>;
```

The glow tracks the microphone signal in real time. When the user is not speaking, the `idle` prop controls the resting height. When speech is detected, the glow rises and blooms in response to amplitude.

## Variants

The `colorVariant` prop sets the palette. `mono` is tuned for the frakment monochrome theme.

## Geometries

The `type` prop controls the glow's geometry.

- **`default`** — a chat input, roughly 350px wide
- **`pill`** — a recording pill, roughly 150×44
- **`mobile`** — a mobile bottom sheet

## Accessibility

- The glow is purely decorative. It is marked `aria-hidden` and does not convey information that is not also present in the surrounding UI.
- Reduced motion is respected: when `prefers-reduced-motion: reduce` is active, the glow renders at a static height without animation.
- Microphone access is only requested when the `stream` prop is provided. For idle-only use, omit `stream`.
