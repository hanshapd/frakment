## Anatomy

```tsx
<Separator orientation="horizontal" decorative />
```

- **Separator** — a single rule. Horizontal by default, or vertical
- `decorative` — when true (default), the rule is visual only and hidden from screen readers

## Orientation

Horizontal rules have `h-px w-full`. Vertical rules have `h-full w-px` — the parent must have a defined height.

## Accessibility

- `decorative` is `true` by default — the separator is not announced by screen readers. This is correct for visual dividers between content sections.
- Set `decorative={false}` when the separator has semantic meaning — it will render with `role="separator"` and be announced.
- For vertical separators, ensure the parent container has a defined height.
