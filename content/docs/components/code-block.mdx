Code Block renders a monospaced code surface with optional header, copy button, line numbers, and per-line variants for diffs.

## Usage

```tsx
import { CodeBlock, CodeBlockContent } from "@/components/ui/code-block";
```

```tsx
<CodeBlock>
  <CodeBlockContent>{"npm install frakment"}</CodeBlockContent>
</CodeBlock>
```

## Basic

The simplest form — pass a string as children of `CodeBlockContent`.

<ComponentPreview name="code-block" title="code-block.tsx">
  <div className="w-full max-w-lg">
    <CodeBlock>
      <CodeBlockContent>{"npm install frakment"}</CodeBlockContent>
    </CodeBlock>
  </div>
</ComponentPreview>

## Header

Wrap the top row in `CodeBlockHeader`. Use `CodeBlockTitle` for the filename and `CodeBlockActions` for buttons.

<ComponentPreview name="code-block" title="code-block.tsx">
  <div className="w-full max-w-lg">
    <CodeBlock>
      <CodeBlockHeader>
        <CodeBlockTitle>
          <FileCode2Icon />
          Terminal
        </CodeBlockTitle>

          <CodeBlockCopyButton value="npx frakment add button" />
        </CodeBlockActions>
      </CodeBlockHeader>
      <CodeBlockContent>{"npx frakment add button"}</CodeBlockContent>
    </CodeBlock>
  </div>
</ComponentPreview>

## Actions

`CodeBlockActions` can hold multiple buttons — copy, download, wrap toggle. Each is a plain `Button`.

<ComponentPreview name="code-block" title="code-block.tsx">
  <div className="w-full max-w-lg">
    <CodeBlock>
      <CodeBlockHeader>
        <CodeBlockTitle>
          <FileCode2Icon />
          install.sh
        </CodeBlockTitle>
        <CodeBlockActions>
          <CodeBlockCopyButton value="pnpm add frakment" />
        </CodeBlockActions>
      </CodeBlockHeader>
      <CodeBlockContent>{"pnpm add frakment"}</CodeBlockContent>
    </CodeBlock>
  </div>
</ComponentPreview>

## Floating Actions

Place `CodeBlockActions` **directly inside** `CodeBlock` (no header) — the buttons float top-end and fade in on hover.

<ComponentPreview name="code-block" title="code-block.tsx">

    <CodeBlock>
      <CodeBlockActions>
        <CodeBlockCopyButton value="npm i frakment" />

      <CodeBlockContent>{"npm i frakment"}</CodeBlockContent>
    </CodeBlock>
  </div>
</ComponentPreview>

## Line Numbers

Add `lineNumbers` to `CodeBlockContent`. Line numbers **are not copied** when the user selects the code.

<ComponentPreview name="code-block" title="code-block.tsx">
  <div className="w-full max-w-lg">
    <CodeBlock>
      <CodeBlockContent lineNumbers>{`import { Button } from "@/components/ui/button"

export default function Page() {
  return <Button>Click me</Button>
}`}</CodeBlockContent>
    </CodeBlock>
  </div>
</ComponentPreview>

## Start Line

Set `startLine` to begin numbering from a different number — useful when showing a snippet from the middle of a file.

<ComponentPreview name="code-block" title="code-block.tsx">

    <CodeBlock>
      <CodeBlockContent lineNumbers startLine={20}>{`  const result = streamText({
    model: "anthropic/claude-sonnet-4.5",
    messages,

  return result.toUIMessageStreamResponse()`}</CodeBlockContent>
    </CodeBlock>
  </div>
</ComponentPreview>

## Diff

Use `variant="added"` and `variant="removed"`. The `+` and `−` markers are added by CSS — no need to type them.

<ComponentPreview name="code-block" title="code-block.tsx">
  <div className="w-full max-w-lg">
    <CodeBlock>
      <CodeBlockContent>
        <CodeBlockLine>{"const config = {"}</CodeBlockLine>
        <CodeBlockLine variant="removed">{"  theme: 'light',"}</CodeBlockLine>
        <CodeBlockLine variant="added">{"  theme: 'system',"}</CodeBlockLine>
        <CodeBlockLine>{"}"}</CodeBlockLine>
      </CodeBlockContent>
    </CodeBlock>
  </div>
</ComponentPreview>

## Accessibility

- **CodeBlockContent** has `tabIndex={0}` for keyboard scroll.
- **CodeBlockCopyButton** has `aria-label` and a `aria-live` region announcing "Copied".
- Use **CodeBlockTitle** as the accessible name of the block.
