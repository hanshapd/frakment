**frakment** is a set of accessible, composable primitives for AI and chat interfaces. Every component is written from scratch, depends only on a small set of well-known libraries, and ships as open source you can read, copy, and modify.

_Primitives for AI and chat — built to be read, copied, and extended._

<Callout type="info" title="Built for AI interfaces">

AI applications have specific UI needs — agent traces, streaming status, chat bubbles, code output — that generic component libraries don't address well. frakment is built around those primitives.

</Callout>

## Principles

### Zero hidden dependencies

Every component depends only on `radix-ui`, `class-variance-authority`, and `lucide-react`. There is no hidden dependency chain you need to install or keep in sync.

### Composable by design

All components follow the same shape: a root (`Bubble`), a content slot (`BubbleContent`), and variants via `cva`. This is predictable for you, and for LLMs reading the code.

### Distribution via CLI and registry

A flat-file registry (`public/r/*.json`) and a CLI (`npx frakment add`) make it easy to distribute components across projects. Each component is a JSON manifest with its source, npm dependencies, and registry dependencies.

### Beautiful defaults for AI

The defaults are opinionated so you don't have to design from scratch. Every component is designed for the AI use case first.

### AI-ready

An `llms.txt` file, agent catalog endpoint, and open source make it easy for AI tools to read, understand, and extend.
